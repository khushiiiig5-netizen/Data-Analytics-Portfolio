# ☕ Café Sales Dashboard

## Overview

An interactive Power BI dashboard designed to analyze café sales and transaction performance across products, months, quarters, locations, and payment methods.

## Key Insights

- Total sales
- Total quantity sold
- Total transactions
- Top-selling items
- Monthly quantity trends
- Item-wise sales performance
- Quarterly transaction trends
- Payment method analysis
- Location-wise analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Business Analytics
