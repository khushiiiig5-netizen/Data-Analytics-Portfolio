# 📚 Bookstore Sales Analysis

## Overview

A SQL-based analysis of a bookstore dataset containing books, customers, and orders. The project explores book performance, customer behavior, sales, revenue, and inventory.

## Key Insights

- Books by genre and publication year
- Customer and order analysis
- Total stock and revenue
- Most and least expensive books
- Books sold by genre and author
- Frequently ordered books
- Top customers by spending
- Remaining inventory after orders

## SQL Concepts Used

- SELECT & WHERE
- ORDER BY
- GROUP BY & HAVING
- JOINs
- Aggregate functions
- Subqueries
- COALESCE
- LIMIT

## Tools

- SQL
- PostgreSQL
