# 🗄️ SQL Projects

A collection of SQL projects demonstrating data querying, analysis, data cleaning, aggregation, joins, and business-oriented problem solving.

## Projects

### 📚 Bookstore Sales Analysis

SQL analysis of books, customers, and orders to explore sales, inventory, customer spending, and book performance.

**Key Areas:**
- Book and genre analysis
- Customer analysis
- Order and revenue analysis
- Inventory analysis
- Customer spending
- Frequently ordered books

**SQL Concepts:** SELECT, WHERE, JOIN, GROUP BY, HAVING, ORDER BY, aggregate functions, subqueries

---

### 🍕 Pizza Sales Analysis

SQL project analyzing pizza orders, sales, revenue, categories, order timing, and product performance.

**Key Areas:**
- Total orders and revenue
- Pizza category analysis
- Order distribution by hour
- Top-selling pizza types
- Revenue contribution
- Cumulative revenue
- Category-wise ranking

**SQL Concepts:** JOINs, GROUP BY, aggregate functions, subqueries, date/time functions, window functions, RANK()

---

### 🛒 Zepto Product Analysis

SQL project focused on product-level analysis, data cleaning, discounts, pricing, availability, and inventory.

**Key Areas:**
- Product category analysis
- In-stock vs out-of-stock products
- Discount analysis
- Estimated category revenue
- Price-per-gram analysis
- Product weight classification
- Inventory weight analysis

**SQL Concepts:** Data cleaning, UPDATE, DELETE, CASE, GROUP BY, aggregate functions, ROUND(), filtering and sorting
