# 📊 Excel Data Analysis

## Overview

An Excel-based sales data analysis project focused on data cleaning, calculation validation, pivot table analysis, and identifying sales trends across regions, products, and months.

## Dataset

The dataset contains sales records with information such as:

- Date
- Region
- Product
- Quantity
- Unit Price
- Total Sales

## Data Preparation

The dataset was cleaned and prepared for analysis before creating the final reports.

Key steps included:

- Organizing and cleaning the sales data
- Calculating Total Sales using Quantity × Unit Price
- Adding error checks using IFERROR
- Creating a separate cleaned dataset
- Adding a month field for trend analysis

## Analysis Performed

- Total sales by region
- Total sales by product
- Region-wise and product-wise sales
- Monthly sales trends
- Sales performance comparison

## Key Findings

- Total sales amounted to 9,790.
- North generated the highest regional sales.
- Product C recorded the highest sales among the products.
- Monthly sales varied significantly across the analyzed period.
