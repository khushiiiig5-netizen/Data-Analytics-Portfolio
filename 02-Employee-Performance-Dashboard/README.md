# 👥 Employee Performance Dashboard

## Overview

An interactive Power BI dashboard designed to analyze employee performance, compensation, demographics, and departmental trends.

## Key Insights

- Total number of employees
- Employee performance ratings
- Annual CTC by department
- CTC by age
- CTC by employee tenure
- Employee age distribution
- Department-wise compensation analysis
- Employee tenure analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Business Analytics
